# Update to Lift & Cut 2.6.4

1. Export a verified backup.
2. Extract the GitHub update ZIP.
3. Upload the extracted root files to `Nfarrugia1985.github.io`.
4. Commit to `main` and wait for GitHub Pages deployment.
5. Refresh once in Chrome, fully close the installed app, then reopen it.
6. Confirm **v2.6.4 / Schema 7** under More → Appearance and app info.

No Google Sheets or Apps Script update is required when coming from v2.6.0+ with the v2.6 backend already installed.

If a live lookup still reports an Apps Script timeout, test **More → Cloud sync → Test**. The local USDA library does not depend on Apps Script.
