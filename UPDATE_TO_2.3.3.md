# Update Lift & Cut to v2.3.3

1. In Lift & Cut, open **More → Backup and spreadsheet → Export full JSON**.
2. Extract `Lift_Cut_GitHub_Recipe_Reader_Update_v2.3.3.zip`.
3. In your GitHub Pages repository, choose **Add file → Upload files**.
4. Upload all extracted files to the repository root and commit to `main`.
5. Wait for GitHub Pages to deploy.
6. Refresh the website once, then fully close and reopen the installed app.
7. Confirm **v2.3.3** under **More → Appearance and app info**.

No Apps Script redeployment and no spreadsheet change are required.

## Using the new features

- Open **Diet → Saved recipes → Open** for the read-only cooking view.
- Tick ingredients as they are prepared and instructions as they are completed.
- Tap a timer beside a timed instruction to start the floating timer.
- During EPUB import, review and edit the detected recipe names before selecting **Import selected recipes**.
