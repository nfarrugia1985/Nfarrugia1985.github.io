# Lift & Cut 2.3.5

## Recipe reader

- Fixed cooking cards collapsing and clipping their checklist content.
- Rebuilt the recipe reader as a true full-screen, independently scrolling view on phones.
- Added separate Ingredients and Instructions tabs so long recipes are not crowded into one screen.
- Increased checkbox rows and timer buttons to phone-friendly touch sizes.
- Added ingredient and step completion counts beneath the progress bar.
- Added Continue to instructions and Back to ingredients controls.
- Reduced the mobile recipe-photo height to leave more room for cooking.
- Added cache-busted CSS and JavaScript URLs to prevent mixed old/new files after GitHub deployment.

No Google Sheets or Apps Script update is required.
