# Update to Lift & Cut 2.3.5

1. In Lift & Cut, export a full JSON backup.
2. Extract the v2.3.5 GitHub update ZIP.
3. Upload all extracted files to the root of the GitHub Pages repository.
4. Commit the replacements to `main`.
5. Wait for GitHub Pages to deploy.
6. Open the website once in Chrome and refresh it.
7. Fully close and reopen the installed app.
8. Confirm `v2.3.5` under More → Appearance and app info.

This release changes only the public website. It does not require a spreadsheet or Apps Script update. Existing recipes and checklist progress are preserved.
