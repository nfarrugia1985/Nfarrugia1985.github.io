# Update to Lift & Cut 2.3.6

1. Export a full JSON backup.
2. Extract the GitHub update ZIP.
3. Upload all extracted files to the repository root and commit to `main`.
4. Wait for GitHub Pages deployment.
5. Refresh the website and fully close/reopen the installed app.
6. Confirm `v2.3.6` under More → Appearance and app info.

No Google Sheets or Apps Script update is required.
