# Update Lift & Cut to v2.3.4

1. Export a full JSON backup.
2. Extract the v2.3.4 GitHub update ZIP.
3. Upload all extracted files to the root of the GitHub Pages repository.
4. Commit to `main` and wait for deployment.
5. Refresh the website, then fully close and reopen the installed app.
6. Confirm **v2.3.4** under More → Appearance and app info.

No Google Sheet or Apps Script update is required.
