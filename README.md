# Lift & Cut 2.3.8

Lift & Cut is a mobile-first, local-first home-gym, nutrition, recipe and progress tracker with optional Google Sheets sync.

Version 2.3.8 is the **Recipe Validation Update**. It strengthens website and EPUB recipe parsing after testing real ingredient formats from multiple Pinch of Yum recipes and the supplied *I Quit Sugar: Simplicious* EPUB. It adds a broader 224-food starter cache, more conservative ingredient detection, improved recipe-title extraction and an editable batch-review workflow.

## Privacy

The public website contains generic starter data only. Personal workouts, recipes, body measurements, sync settings and progress remain in the user's local browser database and optional private Google Sheet.
