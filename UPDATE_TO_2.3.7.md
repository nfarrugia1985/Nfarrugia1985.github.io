# Updating Lift & Cut to v2.3.7

1. In Lift & Cut, export a full JSON backup.
2. Extract the GitHub update ZIP.
3. Upload the extracted files to the root of the `Nfarrugia1985.github.io` repository.
4. Commit the replacements to `main` and wait for GitHub Pages to deploy.
5. Refresh the website, then fully close and reopen the installed app.
6. Confirm `v2.3.7` under **More → Appearance and app info**.

No Google Sheet or Apps Script update is required.

Existing matched recipe ingredients are recalculated automatically on first launch. Standard household conversions are marked **Estimated unit** so they can be reviewed or replaced with weighed values.
