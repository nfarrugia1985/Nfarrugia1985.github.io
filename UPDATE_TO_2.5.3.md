# Updating Lift & Cut to 2.5.3

1. Export a verified JSON backup in Lift & Cut.
2. Extract the v2.5.3 GitHub update ZIP.
3. Upload the extracted root-level files to `Nfarrugia1985.github.io` and commit to `main`.
4. Wait for GitHub Pages deployment, refresh the website in Chrome, then fully close and reopen the installed app.
5. Confirm `v2.5.3` under More → Appearance and app info.
6. Open Program and choose **Modified MLM 6-Day Programme**.

No Google Sheets or Apps Script update is required. The programme is added locally during migration and will be included in the next normal sync.
