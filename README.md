# Lift & Cut

Mobile-first local home-gym, nutrition and progress tracker with optional Google Sheets sync.

## Deployment

Publish the files in this folder from the root of a GitHub Pages repository. `index.html`, `manifest.webmanifest`, `sw.js` and the icons provide the installable/offline app shell.

## Privacy

This public package contains generic seed data only. Do not commit private imports, populated databases, backups, progress photos or Google Apps Script sync keys.

Detailed setup instructions are provided separately in the complete package.
